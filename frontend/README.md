# Q/01 暗色模拟盘终端

这次把观察页重做为高密度暗色交易终端：首屏直接显示 Demo 环境、连接心跳、权益、PnL、持仓/委托数量和风控状态；持仓、委托、成交、资金曲线、运行日志改为同一主舞台 Tab。控制台、模型指纹、交易所映射和历史回放收进次级区域，凭证表单默认隐藏。

## 文件

- `index.html`：新的页面骨架，保留原有业务 ID 和 `app.js` 引用。
- `styles.css`：按终端 token 重做暗色样式、表格、响应式布局和正负颜色。
- `app.js`：保留现有接口协议；新增 `fmtPnl`、主权益两位小数、相对时间、Tab 切换、可选 `markPx/upl` 渲染、会话权益曲线和会话运行日志。顶栏交易所名称来自实际活动 venue，不再硬编码 OKX。
- 控制抽屉：公开页可查看“预检 / 启动 Demo / 停止 / 安全停机”入口，但按钮只读；交易节点本机的 loopback 控制页才允许执行，避免把下单接口暴露到公网。通过 SSH 隧道访问 `127.0.0.1:8080` 后，凭证仍只保存在服务器本机。

## 验证

从 `frontend/server.py` 启动观察页后打开根路径：

```text
python frontend/server.py --host 127.0.0.1 --port 18081
```

检查首屏即可回答：

1. 顶栏胶囊明确显示 `OKX DEMO`，页脚保留 `DEMO / TESTNET ONLY`。
2. 权益、今日 PnL、未实现、已实现按数字显示；正数绿色、负数红色、零值灰色。
3. 默认持仓 Tab 显示方向、数量、均价、标记价/现价、未实现、已实现、杠杆和占用。
4. 顶栏显示连接心跳与 `RUNNING`；运行节点超过 30 秒没有写入心跳时显示 `STALE`，不会把旧状态文件当作在线。
5. 委托 Tab 的空态仍显示“当前无活动委托”和最近成交时间；成交 Tab 显示最近成交时间。

资金曲线仅使用当前浏览器会话的 `localStorage` 权益点，不代表历史账户净值。没有来自接口的 `markPx`、`upl` 或成交 PnL 时保持缺失显示，不以零值代替。

交易安全边界：旧 Bybit legacy runtime 已从 `quant_bot run --mode testnet` 入口禁用；统一运行时在 OKX/Binance Futures 首次衍生品下单前只读核验 isolated 保证金、单向持仓模式和最大 2 倍杠杆，核验失败不会下单。`preflight` 仍然是只读检查，不会自动修改交易所账户设置。
