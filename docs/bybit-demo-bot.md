# Bybit Demo behavioral bot

The runtime is pinned to Bybit Demo Trading. It is not a mainnet connector and
does not fall back to `api.bybit.com` or `stream.bybit.com`.

The strategy remains `BEHAVIORAL_APPROXIMATION`. The deployment artifact is
frozen and loaded at runtime; the bot never trains online. Spot symbols are
monitor-only. The historical model and risk envelope are generated by:

```powershell
$env:PYTHONPATH = "$PWD;$PWD\quant\src"
python quant/scripts/build_cross_asset_deployment_model.py
```

Credentials are read only from the local process environment. Do not paste
them into chat, source files, reports, or logs:

```powershell
$env:BYBIT_DEMO_API_KEY = "your-demo-key"
$env:BYBIT_DEMO_API_SECRET = "your-demo-secret"
```

Run the read-only preflight first:

```powershell
python -m quant_bot preflight --venue bybit-demo
```

For a one-command local launch, use the checked-in PowerShell wrapper. It
reuses the current process environment; if credentials are missing, it asks
for them locally and clears temporary values when it exits. They are never
written to the repository or sent to the dashboard host:

```powershell
.\deploy\start-bybit-demo.ps1 -Mode readonly
```

Use `-Once` for a single read-only cycle. The default is continuous read-only
monitoring. The wrapper is deliberately read-only by default.

Only after preflight passes, a user may explicitly enable Demo orders:

```powershell
python -m quant_bot run `
  --venue bybit-demo `
  --mode testnet `
  --symbols auto `
  --enable-orders `
  --confirm-testnet
```

The equivalent wrapper command requires two explicit confirmations:

```powershell
.\deploy\start-bybit-demo.ps1 -Mode demo -ConfirmTestnet
```

The `--confirm-testnet` flag is retained as a safety-oriented CLI name; it
means “confirm Bybit Demo”, never mainnet. Without both explicit order flags,
the pre-trade gate blocks every order. `Ctrl+C` stops new signals, cancels
orders created by this process, saves ignored runtime state, and disconnects.

Bybit Demo provides private WebSocket account streams but does not provide the
same server-side cancel-after/dead-man switch used by BitMEX. The runtime
therefore uses a local 20-second WebSocket heartbeat, reconnects on disconnect,
and cancels bot-owned orders when the watchdog detects a stale loop or a lost
private stream.

The first real Demo order is intentionally a separate operator action. This
repository does not submit an order merely because credentials exist.
