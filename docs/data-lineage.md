# Data lineage

The lineage chain is:

`frozen account exports → accounting → wallet reconciliation → behavior episodes → public market context → leakage-safe features → strategy fidelity → walk-forward research`.

Each stage records its source commit, analysis commit, UTC coverage, input protection result, and report path in `quant/DATA_LINEAGE.md` or the corresponding report manifest.

The root CSV and JSON exports are protected inputs. They must not be formatted, rewritten, moved, or regenerated.
