# Backtesting

Backtests use the same Strategy Core as streaming-style parity checks. The execution model includes next-bar execution, fees, funding events, configurable slippage, signal delay, exposure and lot limits, tick size, and settlement-currency separation.

The reported return is a normalized exposure-return proxy. It is not the historical BitMEX wallet/account PnL and must not be interpreted as a live capital result.
