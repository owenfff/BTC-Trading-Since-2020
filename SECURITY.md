# Security Policy

- Never commit API keys, API secrets, passphrases, private keys, account IDs, or private logs.
- Live trading is disabled by default and the default live risk/notional limits are zero.
- Do not paste credentials into chat or issue trackers.
- Report suspected credential exposure privately to the repository owner, then revoke the credential.
- Demo/Testnet credentials are not part of the repository and are not required for offline smoke tests.
