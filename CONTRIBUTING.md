# Contributing

1. Keep root historical CSV/JSON inputs byte-read-only.
2. Use a focused branch and record source/analysis commits in reports.
3. Run the direct smoke harnesses when pytest is unavailable.
4. Do not add credentials, private account data, live endpoints, or ignored large outputs.
5. Every experiment records both favorable and unfavorable results.
6. Strategy Core remains exchange-neutral and the default risk gates must stay blocking.
